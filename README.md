# MedLembrete

Versão PWA otimizada para smartphones.

## Instalação
O GitHub Pages deve publicar `index.html`, `manifest.webmanifest`, `sw.js` e a pasta `icons/` na mesma raiz.

No Chrome Android, abra o endereço do GitHub Pages e use **Instalar aplicativo** ou **Adicionar à tela inicial**.

## Importante
A instalação como PWA não transforma o site em APK. Para alarmes Android realmente nativos, ainda será necessário empacotar o projeto como aplicativo Android.
