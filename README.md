# MedLembrete

Aplicativo web mobile-first para lembretes de medicamentos.

## Recursos
- Interface otimizada para smartphones
- Medicamentos fechados por padrão; toque para abrir
- Editar, pausar/ativar e excluir
- Vários horários por medicamento
- Tratamento com início e término
- Opção de uso contínuo/vitalício
- Dias restantes e barra de progresso
- Doses de hoje e histórico
- Armazenamento local

## GitHub Pages
Coloque `index.html` na raiz do repositório e publique pelo GitHub Pages usando `main` e `/ (root)`.
