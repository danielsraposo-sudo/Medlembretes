MEDLEMBRETE — versão inicial

Como usar:
1. Abra www/index.html no navegador do Android.
2. Toque em + Adicionar.
3. Cadastre medicamento, dose e horário.
4. Permita notificações quando solicitado.
5. Use Tomei para registrar e Adiar 10 min para reagendar.

Observação: esta é uma versão web instalável/local. Para alarmes Android nativos confiáveis mesmo com o processo encerrado, a próxima etapa é empacotar a mesma interface em APK com notificações/alarmes nativos.
